Fluid Flow - Interactive Generative Art

Description

Fluid Flow is an interactive digital art project that creates flowing patterns using blue and white particles. It uses HTML, CSS, and JavaScript to create smooth animations that respond to mouse movements.

Features

- Flowing particle animations
- Interactive mouse effects
- Glowing blue and white colors
- Color selection options
- Clear button to reset the canvas
- Full-screen animated background
- Simple and lightweight design

Technologies Used

- HTML5 - Website structure
- CSS3 - Styling and animations
- JavaScript - Particle effects and canvas interaction

Getting Started

Run Locally

1. Clone the repository:
   
   git clone https://github.com/arunreddyyy/generative-art.git

2. Open the project folder in VS Code.

3. Open "index.html" in your browser.

No backend or database is required.

How to Use

1. Open the website in your browser.
2. Move your mouse around the canvas to see the effects.
3. Try the available color options.
4. Click the Clear button to reset the canvas.

Project Objective

The goal of this project is to create interactive digital art using basic web technologies. It shows how particles, animations, and mouse interactions can be used to create interesting visual effects.
